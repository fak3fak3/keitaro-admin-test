# UX-исследование и редизайн фронтенда

Дата: 2026-11-21. Что проверялось: список кампаний, форма New campaign, редактор `/campaigns/217519`
(живой бэкенд, в момент проверки опрос Keitaro отвечал 401). Сверка с видео из ТЗ (раздел
«Поведение редактора» в [PLAN.md](PLAN.md)), решениями №32–37 и [DISPUTED.md](DISPUTED.md).

## 1. Проблемы текущего интерфейса

### Ошибки и предупреждения (главная проблема)

1. **Ошибка действия над потоком показывается одной плашкой над всей страницей.** Пин в потоке
   Offers дал «Закреплено 10%, а остаток 90% некому отдать…» вверху страницы, над потоком Geo.
   Непонятно, к какому потоку это относится; когда потоков несколько, придётся угадывать. Плашка
   ещё и сдвигает все потоки вниз — кнопка, по которой только что кликнули, «уезжает» из-под курсора.
2. **Нет места для постоянных предупреждений потока.** Сейчас у потока Offers в Keitaro 10% на
   единственном оффере — сумма не 100%, и интерфейс об этом молчит. После планируемого изменения
   (сумма ≠ 100 не блокирует, а предупреждает, Push разрешён — как в Keitaro) такое предупреждение
   негде показать.
3. **Ошибка опроса Keitaro (live) — длинный красный текст в шапке**, рядом с кнопкой Fetch:
   «Keitaro недоступен: Keitaro API error (401): Invalid API key». Ширина шапки прыгает, текст
   техничный, а последствие («изменения из Keitaro сейчас не приходят») не сказано.
4. Ошибки Fetch и загрузки потоков — тоже плашка на страницу. Это правильно (они про кампанию),
   но визуально неотличимо от ошибок потока.

### Состояния, которые плохо различимы

5. **Черновик почти не виден**: бледно-жёлтый фон и маленький бейдж «Черновик». Не видно,
   *что именно* изменено: строки с изменённой долей ничем не отличаются, прежнее значение
   (`published_share`) не показано. Перед Push нельзя проверить, что уйдёт в Keitaro.
6. **Удалённый оффер**: `opacity-60` на всю строку, поэтому кнопка Bring back тоже выглядит
   неактивной. Слова removed / «удалён» нет — только серый цвет.
7. **Пин**: незакреплённый оффер показан перечёркнутой булавкой (`PinOff`) — читается как
   «пин выключен/запрещён», а не «можно закрепить». Закреплённый отличается только заливкой.
8. **Нет итоговой суммы долей.** «Цифры верные» — ключевое требование ТЗ, а проверить сумму
   можно только в уме.
9. **Пометки из Keitaro** — мелкий голубой текст под названием; кнопка «Понятно» стоит в футере
   рядом с Cancel/Push без пояснения, к чему она относится.
10. **Конфликты**: красный бейдж в заголовке и «Всё моё / Всё из Keitaro» в футере, а сам выбор —
    в строках. Push неактивен, причина — только в `title` (тултип, на тач-устройствах не виден).
11. **Занятость потока**: во время запроса кнопки просто становятся серыми, без индикатора;
    неочевидно, что идёт запрос, а не что кнопки запрещены.

### Пустые и загрузочные состояния

12. Пока потоки грузятся — пустая страница без индикатора; список кампаний — то же самое.
13. Подсказка «Потоки ещё не загружены. Нажмите Fetch» — обычный серый текст, без кнопки рядом.
14. Поток без офферов (Geo) — только заголовок; не сказано, что он не редактируется здесь
    (это верно по видео, но выглядит как незагруженный).

### Шапка и навигация

15. В крошках «Кампания 217519» вместо имени кампании (имя есть в нашем списке кампаний).
16. В видео в шапке есть View in KT и Show all offers — у нас их нет (решение №36). Clicks today
    в заголовке потока — опциональный шаг 12.

### Список кампаний и форма

17. Плейсхолдер «test_mirolyubov_campaign1» в поле «Название» выглядит как заполненное значение.
    Формат гео («MX,AU,RO») подсказан только плейсхолдером, который пропадает при вводе.
18. Ошибки автокомплита — текст бэкенда как есть («Keitaro API error (401)…») внутри выпадающего
    списка. Допустимо (решение №34: сообщения бэкенда показываем как есть), но без пояснения.
19. Форма стоит над списком — для страницы «Кампании» главное — список; заголовок «Кампании»
    оказывается в середине страницы.

### Расхождения с видео и Keitaro

- Видео: жёлтый поток = черновик — сохранено, но слишком бледно.
- Видео: removed-оффер серый с Bring back — сохранено, но кнопка тоже серая.
- Keitaro сам принимает сумму ≠ 100% (DISPUTED №1, проверено) — у нас это пока ошибка; после
  изменения основной сессии станет предупреждением на потоке.
- Названия кнопок из видео (Fetch streams from KT, Push to KT, Cancel, Add, Remove, Bring back)
  оставляем английскими — так их узнает проверяющий; пояснения — по-русски.

## 2. Предложение редизайна

Логика моделей не меняется, кроме одного места: ошибки действий над потоком хранятся по id потока.

### P1 — обязательно

- **Ошибки и предупреждения — на самом потоке.** В карточке потока под заголовком — область
  уведомлений (`StreamNotices`):
  - ошибка последнего действия над этим потоком (красная, с «Закрыть»; снимается новым действием
    над потоком) — модель: `$streamErrors: Record<streamId, string>` вместо общей `$editorError`
    для действий;
  - постоянное предупреждение «Сумма долей N%, а не 100%» (жёлтое), пока у потока есть активные
    офферы и сумма ≠ 100. Считается чистой функцией `streamWarnings(stream)` — когда бэкенд начнёт
    отдавать предупреждения сам, источник меняется в одном месте;
  - конфликты: «N офферов изменены и у нас, и в Keitaro — выберите версию. Push недоступен, пока
    есть конфликты» + «Всё моё» / «Всё из Keitaro»;
  - пометки Keitaro: «С прошлой загрузки в Keitaro изменились N офферов» + «Скрыть пометки»
    (было «Понятно»).
  На странице остаются только ошибки уровня кампании: загрузка потоков и Fetch.
- **Строка «Итого» в таблице** с суммой активных долей; при ≠ 100 — жёлтым.
- **Черновик заметнее**: жёлтая рамка и полоса слева, бейдж «Черновик · N изменений»; в изменённой
  строке — прежняя доля зачёркнутым «33% → 50%» и метка «новый» у неопубликованного оффера.
- **Removed**: серым только текст оффера и долю, бейдж «removed», Bring back — обычная кнопка.
- **Пин**: незакреплённый — контурная булавка приглушённо, закреплённый — залитая и цветная,
  подпись в `aria-label` прежняя.

### P2 — желательно

- **Live в шапке — компактный индикатор** (точка + «Live» / «Нет связи»); ошибка опроса Keitaro —
  отдельная жёлтая плашка над потоками: «Keitaro не отвечает — изменения из трекера не приходят.
  <текст ошибки>». Это уровень кампании, поэтому плашка на странице, не на потоке.
- **Загрузка**: «Загружаем потоки…» вместо пустоты; занятый поток — спиннер на заголовке
  и `aria-busy`.
- **Пустое состояние** — карточка с текстом и кнопкой Fetch streams from KT прямо в ней.
- **Поток без офферов** — подпись «Офферов нет — фильтры и редирект редактируются в Keitaro».
- **Крошки** — имя кампании, если она есть в нашем списке (иначе id).
- Пометки Keitaro и конфликт в строке — компактные бейджи вместо голубого текста.

### P3 — потом

- Список кампаний — первым, форма New campaign — по кнопке (разворачивается над списком).
- Подсказки под полями формы («Коды стран через запятую: MX,AU,RO»), плейсхолдер имени —
  «test_mirolyubov_…».
- View in KT (нужен адрес админки во фронте — через API настроек), Show all offers, clicks today.

## 3. Согласование и что сделано

Пользователь 2026-11-21 согласовал объём **P1 + P2 + P3** и показ предупреждения «сумма ≠ 100%» уже
сейчас (считается на фронте). Сделано всё из P1–P3, кроме:
- кнопки Fetch внутри пустого состояния — в шапке уже есть та же кнопка, вторая с тем же названием
  только путает (пустое состояние стало карточкой с подсказкой);
- View in KT, Show all offers, clicks today — как и раньше, не делаем (нужны данные, которых у фронта нет).
